01The one rule — real people only

Every byline is a real person or the real company team. Never invented.

  • Default is always a company-wide byline (e.g. "Testlify Team") — not an individual writer
  • Use a named individual only where it genuinely makes sense: founder/CEO for strategy pieces, or when explicitly requested by the client
  • A byline is not a persona. The persona is who the article is written to; the byline is who wrote it. Keep them separate.
  • E-E-A-T (Expertise, Authoritativeness, Trustworthiness) comes from real credentials + cited data + the bio — never a fabricated personal story
Input The team — ask them who the real bylines are. Default company byline, founder voice (if any), and any other named authors.

05Auto-route rules — applied in order

No asking — these rules decide the byline automatically. A named individual is only used when explicitly requested.

PriorityRuleByline
1Topic is leadership / vision / CEO / strategy-at-scale / future-of, OR format is press release / white paper / PR pitchFounder or leadership voice
2Everything elseCompany-wide default byline
3User explicitly asks for a named individual authorThat named individual (e.g. Yashika, Aparna) — use only when asked
Never auto-route to a named individual Even if a recruiter-focused how-to looks perfect for Yashika, it still goes to the default byline unless the client specifically says "use Yashika for this." Named authors are opt-in, not automatic.
