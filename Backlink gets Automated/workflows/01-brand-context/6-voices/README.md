# 6-voices — how to run
The bylines are COMPANY-GIVEN (the recipe's steps 1-4 are questions to the team). The tool only
instantiates the questionnaire skeleton at its SKILL.md stage; answers are SEED, never overwritten,
never machine-drafted. Real people's details live only in projects/<company>/ — never in this tree.
```bash
COMPANY=<slug> python3 scripts/instantiate.py
```
