Model Other Niches — import formats competitors don't have yet

Many link-bait formats work across any niche — calculators, indices, generators, awards. If a format pulled huge links in finance or real estate but no competitor in our niche has built one, that's a fresh, ownable link magnet.

ABuild the swipe library

A swipe library is a menu of formats that already earn links — the shape of the asset, not its subject. Built from two sources, then pre-screened against the brand scope.

0

Load the brand scope

Load competitor-study/output/brand-scope.md — the same anchor built in Method 1's G0. All three methods judge against the same reference. If Method 1 hasn't run, build brand-scope.md from the brand brain now and get user approval first.

1

Source 1 — the proven-formats table (below)

~20 format families from 75 real link-bait pieces. Read every row. Carry it forward as-is: Format · Real example(s) · Headline template · Why it earns links. Nothing rewritten.

2

Source 2 — agent knowledge (3–5 additions)

Recall famous link-magnet formats not already in the table that (a) earned backlinks, not just traffic, and (b) worked across multiple niches. For each, supply the same four fields. No named real example = drop the format.

3

Pre-screen each format on brand fit

For each format: can this be pointed at a subject inside our brand scope? If the obvious subject is off-brand, look for an in-scope subject the same shape could serve before dropping. Drop only formats with no imaginable in-scope subject — log the reason.

For each surviving format, add: In-scope subject (a nameable subject a writer could build on) and a rough Brand fit tag (CORE / TRANSPLANT / ADJACENT). Step C sets the authoritative tag.

4

Pure assembly — one table row per surviving format using the fields from steps 1–3. This file is the input to Step B.

BGenerate one adaptation per format

One format row from format-swipe.md → one adaptation. Don't ask for five variations. Most formats yield exactly one strong idea.

For each swipe row, run a prompt giving the agent: the format shape, headline template, why it earns links, the real example, and the in-scope subject. The agent works in this order — substance before name:

  • Our topic — sharpen the in-scope subject from Step A to a precise, nameable subject grounded in the brand brain
  • Distinct angle — one line on what makes our version the link-magnet. Must name the specific product, data, or authority we own. If it could be written without the brand brain, it's too generic — rewrite.
  • Asset — only now, a real working title with the angle visible in the name. Never "Format on Topic" glued together.
  • What it'd be — 1–2 lines on what the actual asset is, concretely
Example — Cost Calculator format adapted for a hiring-tech company
Our topicCost of a mis-hire (salary + recruiting + ramp + productivity loss)
Distinct angleLive calculation on our anonymised customer cost data with a per-role breakdown — competitors use generic Glassdoor averages
AssetBad-Hire Cost Calculator (per-role, on real customer cost data)
What it'd be4-input form (role, salary, location, ramp months) → live cost output + sourced formula + sharable PDF

CFilter — the real scored gate

Step A pre-screened formats lightly. Step C filters real adapted ideas against the same two tests Methods 1 and 3 use. Expect to drop a material chunk — that's the filter working. Expect 8–20 surviving ideas, not 50.

Test A — Ownability

  • Does it sit inside the brand scope (CORE / TRANSPLANT / ADJACENT)?
  • Does the company have the data, product, or authority to speak credibly on it? The Distinct angle must name a specific one.
  • Does building it reinforce the brand?

Before dropping an out-of-scope idea, run the transplant check: can the format be pointed at an in-scope subject? If yes, keep as TRANSPLANT. The Ownability verdict here is the authoritative Brand fit tag — it supersedes Step A's rough pre-screen.

Test B — Linkability

  • Is there a citable number the asset could produce?
  • Would a journalist reference it when writing about the niche?
  • Is it evergreen?
  • Does it fit a proven link-bait format? (For Method 2 this is automatically yes — so ≥2 of the other 3 needed.)

Needs ≥3 of 4 yes to pass. Log every KEEP / DROP with a one-line reason.

DScore each surviving idea

Same scales as Method 1. Method 2 has no in-niche competitor page to measure against, so Beatability scores how easy it is to make the asset itself link-worthy.

Beatability (1–3)

  • 3 — simple format, short build (glossary, basic calculator)
  • 2 — moderate (interactive tool, data-light index, definitive guide)
  • 1 — heavy (proprietary data report, complex interactive)

Effort (S / M / L)

  • S — days to a week
  • M — weeks
  • L — a month or more

EWrite the deliverable

Output model-other-niches-ideas.csv with all 12 columns. Sorted: Brand fit (CORE → TRANSPLANT → ADJACENT) → Evidence × Beatability desc → Effort (S first).

  • Idea # — numbered as M2-001, M2-002 etc. The "M2" prefix keeps these ideas distinct from Method 1 and Method 3 ideas when all three pools are combined later.
  • Method — always "M2 — Other Niches", so the combined sheet can be filtered by source
  • Brand fit — CORE / TRANSPLANT / ADJACENT, set by Step C
  • Asset — the real working title from Step B, with the angle visible in the name
  • Format — the format shape (calculator, index, glossary etc.) from the swipe library
  • Our topic — the specific subject the asset covers, from Step B
  • Distinct angle — what makes our version the link-magnet, naming the specific product, data, or authority we have that lets us own it
  • Source niche — where this format is already proven (finance, real estate, B2B SaaS etc.)
  • Evidence URLs — the real example URLs from the swipe library, so anyone can verify the format earns links
  • Beatability — 1–3 (how easy the asset is to make link-worthy)
  • Effort — S / M / L (how long to build it)
  • Notes — the headline and "what it'd be" description from Step B, plus anything else worth flagging
