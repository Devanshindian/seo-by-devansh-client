## How it works
Connect Testlify with Zapier in just a few simple steps and start automating your talent assessment process. Here’s how it works:
- Log in to your Zapier account.
- Click on your profile icon and navigate to Settings>API Key.
- Generate a new API key by clicking on ‘Generate Key’.
- Scroll down to the ‘Integrations’ section (located just below API Key).
- Choose Testlify from the provided list of integrations.
## Set up the integration
Make sure to verify with Zapier that your plan and access level are suitable for proceeding with this stage. Within your Zapier account:
- Generate a new zap in your account.
- Opt for Testlify as your application and pick an occurrence.
- Establish a connection with Testlify and proceed to click on the Sign in button.
- Enter the API key into the designated field.

### Is Zapier integration available in all Testlify plans?

### How can I obtain the API key required for Testlify’s Zapier integration?
To get the API key for Testlify’s Zapier integration, you need to be a Testlify Admin or Owner. Simply log in to your Testlify workspace account, navigate to Settings, then go to the API Key section. Click on “Generate Key” to create a new API key, and make sure to copy and save it securely.
