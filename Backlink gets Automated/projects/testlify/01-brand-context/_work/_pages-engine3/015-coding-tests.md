## Frequently asked questions (FAQs)
Want to know more about Testlify? Here are answers to the most commonly asked questions about our company.
How does the evaluation for coding and programming tests work?
The evaluation is based on test cases that the code is evaluated against. Candidates’ submissions are run through these test cases, and their score is determined by how well their code performs, ensuring accuracy and efficiency in the assessment.
How can Testlify help recruiters make better hiring decisions?
Testlify’s unique features provide recruiters with the tools they need to evaluate candidates accurately and efficiently, ultimately leading to better hiring decisions.
Does Testlify support multifile coding questions?
Yes, Testlify fully supports multifile coding questions, allowing candidates to work on more complex coding tasks and projects in a real-world environment.
Does Testlify offer time-limited tests?
Yes, Testlify offers a range tests to choose from, enabling you to create tests that accurately assess a candidate’s programming skills within a specified timeframe.
Which languages/technologies does Testlify support for multifile coding questions?
Currently, Testlify supports Node.js, Python, and Java for multifile coding questions, providing flexibility for diverse coding assessments.
