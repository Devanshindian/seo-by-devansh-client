42 out of what? — how this narrowed

320 cards used in the plan → 120 carry a number → 42 needed a published source and were checked
Not every number needs a citation. Step numbers, years, list counts and plain durations ("a 30-day notice period") are skipped on purpose. What gets checked is a statistic, benchmark, study result, price, or a claim naming a specific study, law or company. So a small number here is normal; a small number next to a large card count is not a sign the check was skipped.

VERIFIED = the page it credits really does back the claim. REPAIRED = the original page did not, so we searched and found one that does. CUT = we searched and found nothing, so the claim was removed. UNLOADABLE = the page would not open (paywall or block), so we kept the card unchecked rather than punish it. UNCHECKED = we ran out of search budget.
