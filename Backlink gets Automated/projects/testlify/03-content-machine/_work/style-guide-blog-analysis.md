# Style-guide — merged blog analysis (top 30 blogs, 3 batches)

Majority wins for yes/no; union + dedupe for lists.

| Signal | Observed value (merged across the top 30) |
|--------|-------------------------------------------|
| headline_case | **Sentence case** (capitalize first word + proper nouns only). Exception: role names in interview-question listicles are Title-Cased ("60 Maintenance Technician interview questions") |
| brand_naming | **"Testlify"** always capitalized, one word, never stylized; possessive "Testlify's". Features written descriptively in lowercase ("skills assessments", "conversational AI interviews", "test library", "proctoring"); named tests/frameworks Title-Cased ("Cognitive Ability Test", "Candidate Data Profile (CDP)"). Competitors keep native casing (TestGorilla, Adaface, Mercer Mettl, iMocha, HireVue, HackerRank) |
| industry_terms | skills assessment · skills-based hiring · candidate · recruiter · hiring manager · talent acquisition · time-to-hire · time-to-fill · cost-per-hire · quality of hire · aptitude test · situational judgment test (SJT) · job description / job specification · culture fit · pre-employment testing · onboarding · power skills (= soft skills) · blue-/white-/pink-collar · 360-degree feedback · 9-box grid · candidate experience · proctoring · high-volume hiring · structured interview · unconscious bias · employer brand. *(Inconsistencies to fix: "pink collar" vs "pink-collar"; metric names Title-Cased in FAQs but lowercase in body)* |
| oxford_comma | **Yes** (dominant across all 3 batches) |
| em_dash_usage | Em dashes **rare and inconsistently rendered** (often closed, no spaces, for asides); **hyphens preferred** for compound modifiers (skills-based, role-specific, data-driven) and ranges |
| quote_style | **Curly** — curly double for quotations/pull quotes, curly single for scare-quoted terms; curly apostrophes |
| ellipses | **Essentially absent** — the few instances are accidental double-periods. Avoid |
| number_style | **Numerals for all stats/data** — percentages (40%), money ($4,700; ₹ for India), measurements, ranges (2–4 weeks / 15% to 30%), list & step counts (7 questions, Step 1). Commas in large numbers (500,000). Small numbers in prose occasionally spelled but numerals dominate |
| acronyms | ATS, HR, HRIS, DEI, KPI, SMART, SJT, EEOC, ROI, NPS, CI/CD (+ AI, SEO, IQ, EQ, STEM, SHRM, CXO). **First-use expansion is inconsistent in current blogs — enforce it** |
| preferred_words | candidates (not "applicants") · recruiters / hiring managers / talent acquisition teams · skills-based hiring · power skills · structured interview · culture fit · role-specific · objectively evaluate · reduce bias · make informed hiring decisions · screen out / shortlist · high-volume hiring · **attribute stats to a named source** ("According to SHRM/McKinsey"). CTA: "Book a free 30-minute live demo" / "Try for free" / "Explore our test library". Cleaner recent blogs use short sentences + plain verbs ("Start with the work, not the wish list") |
| avoided_words | Hype / AI-cliché (all present in current blogs — cut): "in today's rapidly evolving / fast-paced landscape", ever-evolving, delve, dive into, navigate through, unlock the potential/power, harness the power of, seamless, streamline (overused), robust, holistic, comprehensive, at scale, "hiring game", journey, empower, cornerstone of success, beacon of hope, linchpin, needle in a haystack, take to the next level, win-win, future-proofing, elevate, ripple effect, no easy feat, "the secret to", "there you have it", "But don't worry!", in short / in essence, "it's not just X; it's Y". Overused transitions (However/Additionally/Moreover) + the "Remember," paragraph-opener tic |

**Cross-batch note:** older blogs (talent-management, performance-cycle, interview-question listicles) carry most of the hype/filler; recent blogs (job-description-vs-job-specification, halo-and-horn) are noticeably tighter (short sentences, plain verbs, sourced stats, TL;DR boxes) — that tighter register is the target.
